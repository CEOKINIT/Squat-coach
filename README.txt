KINIT 동작 카운터 (시제품)

[휴대폰에서 쓰는 방법]
카메라는 https 주소에서만 켜집니다. 이 폴더를 GitHub Pages 등에 올려 주소를 만든 뒤 안드로이드 크롬으로 엽니다.
1) GitHub 가입 후 새 저장소(Public) 만들기
2) "uploading an existing file"로 이 폴더 안의 파일 전부 올리기 (폴더째가 아니라 파일 전체)
3) Settings > Pages > Branch: main / (root) 저장
4) 1~2분 뒤 표시되는 주소를 크롬에서 열기. 처음 열 때 한 번 자동으로 새로고침됩니다.
5) 휴대폰을 거치대에 세우고 전신이 보이게 한 뒤 [카메라 시작]

[알아둘 것]
- 영상은 기기 밖으로 나가지 않고 휴대폰 안에서만 분석합니다.
- 속도가 느리면 화면 아래 "분석 해상도"를 "속도 우선"으로 바꿉니다(정확도는 떨어집니다).
- 코칭 문구의 기준은 검증 전입니다.
